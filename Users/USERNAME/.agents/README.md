# AI Agent

## 常用插件

- [Karpathy-Inspired Claude Code Guidelines](https://github.com/multica-ai/andrej-karpathy-skills)
- [playwright](https://github.com/microsoft/playwright-cli)，方便基于本地浏览器查询/操作/测试
- [superpowers](https://github.com/obra/superpowers)，强大的需求分析/开发插件
- [ccusage](https://github.com/ccusage/ccusage), [ccstatusline](https://github.com/sirmalloc/ccstatusline), [claude-hud](https://github.com/jarrodwatts/claude-hud)，Claude Code 状态栏，比自带的 `/statusline` 可玩性高，其中 ccusage 也支持其他 AI 编程工具
- [oh-my-claudecode](https://github.com/Yeachan-Heo/oh-my-claudecode), [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent), [oh-my-opencode-slim](https://github.com/alvinunreal/oh-my-opencode-slim)，给 AI 编程工具封装工作流，提高结果确定性（也会更耗 Tokens）
- [ECC(之前叫 Everything Claude Code)](https://github.com/affaan-m/ECC)，来自 Anthropic 黑客马拉松获胜者的完整 Claude Code 配置集合，因扩展支持了更多 AI 编程工具而改名 ECC
